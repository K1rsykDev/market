# GameHub Marketplace

Простий marketplace для гравців з реєстрацією, авторизацією, ролями та адмін-панеллю. Побудований на Flask + SQLite.

## Запуск
1. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустіть сервер:
   ```bash
   python app.py
   ```
   База даних та базові ролі створюються автоматично.

## Можливості
- Реєстрація та вхід користувачів (логін + пароль + Discord).
- Профіль з загальною інформацією та оголошеннями користувача.
- Створення, редагування та видалення власних оголошень із фото (URL) або плейсхолдером.
- Головна сторінка з фільтрацією по категоріях та сортуванням за датою/ціною.
- Ролі (Member, Moderator, Admin) з правами на видалення та адміністрування.
- Адмін-панель для управління оголошеннями, користувачами та ролями.
